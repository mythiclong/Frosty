### 新模块（参考 V5-Client JS 重写，经 grill-me 拷问拍板）

### ClickGUI 打开即崩（EXCEPTION_ACCESS_VIOLATION）根因与修复
- 崩溃栈：GlassRenderer.draw → RenderPass.setPipeline → vkCmdBindPipeline 读 0x0
- 用户环境：26.2 Vulkan 后端 + NVIDIA 555.97 旧驱动
- **26.2 Vulkan 后端重要规则（字节码实锤）**：`VulkanRenderPipeline.compile()` 只在 `RenderPipeline.getDepthStencilState()==null` 时才创建无深度管线变体，否则 withoutDepthPipeline=0；而 `isValid()` 只查 withDepthPipeline → 空句柄漏检 → 绑定即崩
- 修复：GlassRenderer 的 blurPipeline 不再设 DepthStencilState（模糊 pass 无深度附件）；glassPipeline 保留（合成 pass 主目标带深度）
- 教训：26.2 自定义 RenderPipeline 必须按目标 RenderPass 是否有深度附件来决定是否设置 DepthStencilState
